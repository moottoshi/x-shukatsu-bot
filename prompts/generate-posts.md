# 次の30本を生成するプロンプト

投稿ストックを使い切ったら、このファイルの中身をそのまま Claude Code に貼る。
Claude Code のサブスク内で動くので、API 課金は発生しない。

---

`posts.json` の投稿を次の30本に入れ替えてください。

## 手順

1. `state.json` の `history` を読み、直近で投稿済みの内容を把握する
2. `posts.json` を新しい30本で丸ごと書き換える
3. `state.json` を `{"nextIndex": 0, "history": []}` にリセットする
   (history を残したい場合は別ファイルに退避してから)
4. `node scripts/post.mjs --check` を実行し、30本すべて ok になることを確認する

## 内容の配分

- `tekisei` 10本 — 適性検査(非言語)の解き方。損益算・速度算・割合・集合・仕事算・濃度算
- `es` 7本 — ES の書き方。ガクチカ、自己PR、志望動機
- `mensetsu` 7本 — 面接、逆質問、GD、オンライン面接
- `danddori` 6本 — 就活全体の進め方、スケジュール管理、OB訪問

`tekisei` カテゴリのうち 8本程度に `https://tekisei-drill.vercel.app` を末尾に入れる。
X が OGP カードを自動で描画するので、画像を添付しなくても目を引く見た目になる。

## 守ること

### 事実性(これは好みではなく法律の制約)

- **「適性検査は7割で通過」のような数字を書かない。**
  通過基準は企業ごとに設定され公表されていない。出典のない通説なので使わない
- 「必ず受かる」「確実に内定」など成果を保証する表現を使わない
- 内定率・利用者数などの数字は、出所を確認できないものは書かない
- 企業名を出して選考情報を断定しない。締切や選考フローは変わるうえ、
  間違えるとアカウントの信用が一度で消える

### 書き方

- 1本あたり重み付き280文字以内(日本語は1文字=2、URLは一律23で計算される)。
  `--check` が通らなければ短くする
- 冒頭1行で「誰の何の悩みか」がわかるようにする。X はここしか読まれない
- 抽象的な励ましを書かない。明日そのまま使える具体的な手順を1つだけ書く
- 絵文字は使わないか、使っても1本に1個まで
- ハッシュタグは `#28卒` を基本に、多くても2個まで
- 過去の投稿(`state.json` の history と、前回の posts.json)と
  同じ本文にしない。X は完全一致の重複投稿を拒否する

## 出力形式

`posts.json` の既存フォーマットを維持すること。

```json
{
  "posts": [
    { "id": "p001", "category": "tekisei", "text": "..." }
  ]
}
```
