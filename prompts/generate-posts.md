# 次の30本を生成するプロンプト

投稿ストックを使い切ったら、このファイルの中身をそのまま Claude Code に貼る。
Claude Code のサブスク内で動くので、API 課金は発生しない。

---

`posts.json` の投稿を次の30本に入れ替えてください。

## 手順

1. `state.json` の `history` を読み、直近で投稿済みの内容を把握する
2. **前回の `posts.json` を `git show HEAD:posts.json` で読み、本文が重複しないようにする**
3. `posts.json` を新しい30本で丸ごと書き換える
4. `state.json` を `{"nextIndex": 0, "history": []}` にリセットする
   (history を残したい場合は別ファイルに退避してから)
5. `node scripts/post.mjs --check` を実行し、30本すべて ok になることを確認する
6. `node scripts/make-schedule.mjs <開始日>` で予約リストを作り直す

## 内容の配分

**書くのは2種類だけ。** 2026-08-10(第2弾)に運営者の指示でこの形に変えた。

- `mondai` **14本** — 適性検査の1問を出して、答えと解き方まで1投稿で完結させる
- `kotsu` **16本** — 分野ごとの解き方のコツ、取り違えやすいところ

**★就活のアドバイスは書かない。** ES の書き方・面接・逆質問・スケジュール管理は
第1弾でやっていたが、第2弾からはやめた。アカウント名が「適性検査ドリル」なので、
**問題とコツだけに絞ったほうが何のアカウントか一目で伝わり、ドリルへの送客も増える。**
`es` / `mensetsu` / `danddori` のカテゴリはもう使わない。

**★30本すべての末尾に `https://tekisei.kantan-check.com` を入れる。**
これも運営者の指示(2026-08-10)。全投稿がアプリへの導線になる。
X が OGP カードを自動で描画するので、画像を添付しなくても目を引く見た目になる。
※ API投稿(方法1)ではリンク付きが1本 $0.20 になるが、**現在は方法2(手で予約)で
運用しているので費用は発生しない。** 方法1へ戻すときはこの点を再検討すること。

分野は非言語8つ(損益算・速度算・割合・集合・仕事算・濃度算・推論・表の読み取り)と
言語4つ(語句の意味・二語の関係・熟語の成り立ち・文の並べ替え)を一巡させてから
2周目に入る。`mondai` と `kotsu` は交互に並べると飽きられにくい。

## 出題(`mondai`)を作るときの決まり

- **答えは必ず整数か、小数1桁までに収まる数にする。** 割り切れない組み合わせは
  作り直す。暗算で検算できないと、読んだ人が確かめられない
- **数値は必ず `node -e` で検算してから書く。** 2026-08-10 は12問すべて検算した
- **解き方は1〜2行で書く。** 式を書き切れないなら、その問題は投稿に向いていない
- **「よくある間違い」を1行添える**(割引を忘れて定価を答える/単位をそろえない/
  両方に該当する人を二重に数える)。実際の適性検査の誤答選択肢がこの作りなので、
  ここが読む価値になる
- **実在する検査の問題文を転載しない。** 出題の類型は算数の一般的な分類なので
  自分で作る。`tekisei-drill` の `lib/problems.ts` と同じ方針

## 守ること

### 事実性(これは好みではなく法律の制約)

- **「適性検査は7割で通過」のような数字を書かない。**
  通過基準は企業ごとに設定され公表されていない。出典のない通説なので使わない
- 「必ず受かる」「確実に内定」など成果を保証する表現を使わない
- 内定率・利用者数などの数字は、出所を確認できないものは書かない
- 企業名を出して選考情報を断定しない

### 書き方

- 1本あたり重み付き280文字以内(日本語は1文字=2、URLは一律23で計算される)。
  **URLを入れると本文は日本語100〜110文字が上限**になる。`--check` が通らなければ短くする
- 冒頭1行で「何の話か」がわかるようにする。X はここしか読まれない
  (`mondai` は `【今日の1問】` で始めると、続きが読まれやすい)
- 絵文字は使わないか、使っても1本に1個まで
- ハッシュタグは `#28卒 #29卒 #SPI` の3個。それ以上は視覚的なノイズとみなされてリーチが落ちる
  - 解き方は学年に関係ないので 29卒 まで広げている。30卒 は 2027年夏に足す
- 過去の投稿(`state.json` の history と、前回の posts.json)と
  同じ本文にしない。X は完全一致の重複投稿を拒否する

## 出力形式

`posts.json` の既存フォーマットを維持すること。

```json
{
  "posts": [
    { "id": "p201", "category": "mondai", "text": "..." }
  ]
}
```

id は弾ごとに番号帯を変える(第1弾 p0xx / 第2弾 p1xx / 第3弾 p2xx)。
